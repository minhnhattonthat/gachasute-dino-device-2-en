# Glossary - Gachasute! Dino Device 2 - Dragon (GBA)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.
Source research: docs/terms_proposal.md (portrait evidence, scene notes).

## Rulings (user, 2026-10-14)
- Honorifics: dropped. Name order: Western (given name first).
- Romanisation source: the game's own English (title logo "Dino Device", boot screen "DINO CHARGE", "Dinomo"), else Hepburn; dino/monster names localized when they are puns.
- Credits: English. All graphics text in scope (title logo included).
- Abbreviations: full names and terms everywhere; prefer engine changes (VWF, wider boxes, extra pages) over shortening.
- Workflow: pre-approved; keep going through phases, report at milestones.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> '...', ・・・ -> ..., ！？ -> ?!, 〜 drawl -> drop or a single ~ sparingly.
- Kid-friendly register (target audience: children); lively, short sentences, contractions.
- Currency: ビット = Bits, capitalised, after the number: "500 Bits".
- Fullwidth Latin in the JP (ＯＫ, ＳＴＡＲＴ, Ａボタン) -> normal ASCII ("OK", "START", "A Button").
- Number/name inserts ([E0 11 ..], [E0 12], [E0 18] ...) stay where English grammar needs them; never glue a suffix.
